FULL THIRD-PARTY LICENSES

The individual license documents in this directory accompany the APK and source bundle. They are intentionally kept outside the installed app's UI.

- OPENVPN_FOR_ANDROID_LICENSE.txt: OpenVPN for Android / ics-openvpn GPL v2-or-later license text and linking exceptions at v0.7.64.
- OPENVPN_FOR_ANDROID_THIRD_PARTY_LICENSES.txt: text conversion of the corresponding upstream full_licenses.html, covering the bundled engine's third-party notices.
- LZO_COPYING.txt: upstream LZO license text.

See SOURCE_INFO.txt for exact upstream versions and instructions for obtaining the matching native source with its Git submodules.
