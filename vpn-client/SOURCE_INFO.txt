OpenVPN engine source
---------------------
The vpnLib module identifies OpenVPN for Android version 0.7.64 as its source. The upstream tag resolves to commit:
  73ce3c99dde39207990d66c21be8201228cd1f09

The tag uses Git submodules for native OpenVPN, OpenVPN 3, OpenSSL, mbedTLS, ASIO, LZ4, fmt, and related source. The codeload archive does not include Git submodule contents. To obtain the matching native source tree with the submodules, run:
  ./scripts/fetch-openvpn-native-source.sh

The OpenVPN for Android license and third-party license texts are included in LICENSES/. The bundled native binaries are under vpnLib/src/main/jniLibs/.
